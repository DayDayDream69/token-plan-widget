# Token Plan 用量挂件 · 使用说明

一个浮在桌面上的小卡片，随时查看你的 Token Plan 剩余额度。

Windows 和 macOS 都能用。

---

## 一、怎么打开

### Windows

双击 `Token Plan.exe`。

> 第一次运行 Windows 可能提示「未知发布者」：点「更多信息」→「仍要运行」。

打开后屏幕上会出现一个小胶囊（默认在右下角），显示你的已用百分比。

> 如果没看到，看屏幕右下角的**系统托盘**（时间旁边的小图标区），找一个**绿色圆点图标**，点一下它。

### macOS（Intel 和 Apple 芯片都支持）

1. 解压后得到 **`Token Plan.app`**，把它拖进「应用程序」文件夹（或随便放哪里都行）
2. **第一次打开需要解除系统拦截**（因为没做 Mac 签名，从浏览器下载的应用会被 macOS 加隔离标记，双击会提示"已损坏，无法打开"或"无法验证开发者"）：
   - 打开**终端**（Terminal.app，在 启动台 → 其他 里，或用 Spotlight 搜 "终端"）
   - 粘贴下面这行命令，回车（如提示输入密码，输入你的开机密码，输入时不显示，输完回车即可）：

     ```
     xattr -dr com.apple.quarantine "/Applications/Token Plan.app"
     ```

     > 如果 app 没放在「应用程序」文件夹，把路径换成实际位置（可以直接把 app 拖进终端窗口，路径会自动填上）
   - 之后双击打开就不会再问了
   - （备选：也可以不敲命令，右键 app → 打开 → 再点「打开」；或去 系统设置 → 隐私与安全性 → 点「仍要打开」。但新系统可能没有这个按钮，敲命令最可靠）
3. 打开后小胶囊出现在屏幕上，菜单栏（屏幕右上角）会有一个**闪电图标**

> 菜单栏的闪电图标会自动适应菜单栏深浅色（浅色菜单栏是黑色、深色是白色）。点击它可以显示/隐藏挂件，右键有更多选项。

---

## 二、第一次使用：填 Key

1. **单击那个小胶囊**，会弹出一个面板
2. 面板里会自动出现一个输入框，让你填 **API Key**
3. 填入你的 Token Plan Key（`sk-` 开头的那一串），点「**保存并查询**」
4. 成功后会显示你的剩余积分

Key 只需要填一次，之后会自动记住。查询是每 30 秒自动刷新。

> **Key 存在哪？** 只存在你自己电脑的
> `C:\Users\你的用户名\AppData\Roaming\TokenPlanWidget\config.json`
> 不会上传到任何地方，也不会和别人共享。

---

## 三、三种样子，随你挑

展开面板后，底部有三个按钮可以切换外观：

| 样式 | 长什么样 | 适合谁 |
|---|---|---|
| **胶囊** | 一条窄窄的横条，显示百分比 | 想省地方 |
| **圆环** | 一个圆圈，中间是百分比 | 想要最小的 |
| **迷你条** | 稍大一点，带进度条和剩余额度 | 想一眼看全 |

三种都能用鼠标**直接拖着移动**，位置会记住，下次打开还在那儿。

---

## 四、能看什么

面板顶部有两个标签：

**① 套餐概览**
- 剩余积分（大字）
- 已用 / 总额
- 额度状态（充足 / 即将用尽 / 已用尽）
- 套餐周期和到期日
- 你在所有 Key 里的用量排名
- 最后同步时间

**② 模型用量**
- 选「今天 / 近 7 天 / 近 30 天」
- 看每个模型分别花了多少积分

> 模型用量是**估算值**，服务端汇总会有几分钟延迟，属正常现象。
> 这个功能只对企业版专业套餐开放，普通 Key 可能查不到。

## 五、其他操作

| 操作 | 效果 |
|---|---|
| 单击悬浮体 | 展开详情 |
| 拖动悬浮体 | 移动位置 |
| 按 `ESC` | 收起面板 |
| 右键托盘图标 | 换样式、总在最前、重新查询、设置 Key、退出 |
| 左键托盘图标 | 显示 / 隐藏挂件 |
| 点面板右上角 ↻ | 立刻刷新 |
| 点面板底部「更换 Key」 | 换一个新的 Key |

**想关掉它**：右键托盘图标 → 退出。

## 六、遇到问题

**Windows 提示"未知发布者"，不让运行**
这是正常的。因为这个程序没有花钱买代码签名证书。点「**更多信息**」→「**仍要运行**」即可。

**双击后没反应 / 找不到窗口**
看系统托盘有没有绿色圆点图标，点一下。如果托盘也没有，说明程序没启动成功，重新双击一次。

**提示"Key 无效"**
- 确认 Key 是 `sk-` 开头的完整一串，没有多余空格
- 确认这个 Key 没有被停用或轮换过
- 可以在浏览器里试试：把 `<你的Key>` 换成真实的
  `https://token.m8bj.cn/api/me/usage` 用 Postman 之类的工具带 `Authorization: Bearer <你的Key>` 访问

**提示"无法连接查询服务"**
检查你的网络或代理。如果开了代理，确认 `token.m8bj.cn` 能正常访问。

**数据不更新 / 一直显示旧的**
点面板右上角 ↻ 手动刷新。如果一直失败，可能是服务端数据同步延迟（它每 60 秒同步一次）。

**想看详细错误日志**
打开：`C:\Users\你的用户名\AppData\Roaming\TokenPlanWidget\widget.log`

## 七、几个说明

- **它不读取你的对话内容**，只做一件事：拿你的 Key 去查用量
- **不改任何系统设置**，不在开机启动项里，不驻留后台服务
- **卸载**：直接删掉 exe 文件即可。如果想连配置一起清掉，删掉
  `C:\Users\你的用户名\AppData\Roaming\TokenPlanWidget` 这个文件夹
